## Scope (from the user's brief)

Only the Legacy **Home** page changes. All other Legacy pages stay as they
are. Keep: lavender workspace background, dark navbar (H1–H4), routing, data
logic. Copy from the New frontend Home: width, hero proportions, KPI row,
compact Quick Actions, line icons, tight spacing and one shared grid.

Everything is scoped to `#home` / `.home-container` / `.hd-*` / `.feature-card`.
Verified by grep: `.hd-page-*`, `.hd-welcome*`, `.hd-kpi*`, `.hd-quick-actions`,
`.hd-panel*`, `.feature-card*`, `.feature-btn` are defined only in
`frontend/css/home.css` and used only by the Home section — so restyling them
cannot touch other pages. (`hospital_directory.css` has unrelated `.hd-body/.hd-row`
names; not touched.)

## Slices

Each slice is CSS/HTML only, no backend, and ships with before/after
screenshots at 1440px and 1920px (plus 1366px).

- **HD-1 — Width + shared grid.** Widen Home only: `body:has(#home.active) .container { max-width: 1600px }`,
  `.home-container` max-width 1600px / no centering cap, 32px side padding on desktop
  (24px ≤1200px, 16px ≤680px). The full-bleed navbar's `calc(50% - 50vw)` offset
  stays correct because the container remains centered. Title, hero, KPI row,
  Quick Actions and Alerts share the same left/right edges.
- **HD-2 — Hero.** Height ~260–300px, text column max 560px, keep readable left /
  photo right. Reuse `assets/welcome-hero.jpg` (identical 1600×533 source as the
  New app, so no new asset). Re-tune the left gradient so it stays legible at the
  new, wider crop. Keep the 3 theme tints (`color-mix` on `--brand-*`).
- **HD-3 — KPI row polish.** Keep data/logic untouched. Match New: consistent card
  height, compact padding, stronger number hierarchy, 2-col under 900px (currently
  1200px). Remove the hover lift if it reads as noisy next to the new bar.
- **HD-4 — Compact Quick Actions (the main change).** Replace tall `.feature-card`
  markup in `index.html` with whole-card clickable actions: line-icon tile + title +
  one-line description + arrow. Grid `1.4fr 1fr 1fr 1fr`. New ISBAR Entry stays the
  solid purple primary; the other three white/neutral. Remove the four inner
  buttons (Start Entry / View Beds / View History / View Statistics) and the emoji.
  Icons are the legacy navbar SVGs (Patients, Live ER bed, History, Statistics).
  Cards become `<button>`/`role=link` elements with `onclick="showSection(...)"`
  unchanged, so keyboard access improves rather than regresses.
- **HD-5 — Spacing + lower panel alignment.** One vertical rhythm (24px) between
  header → hero → KPI → Quick Actions → Alerts; tighter title→hero gap. Alerts panel
  adopts the same width and radius. Leave Recent Activity / System Status out
  (still needs the backend decisions recorded in `0. Slicing Task Table.md`).
- **HD-6 — Responsive + regression.** Check 1366 / 1440 / 1600 / 1920 / ~1100 / mobile,
  all 3 themes. Update `tests/home-dashboard.spec.js` if it asserts on the removed
  buttons; add assertions for: whole-card click navigates, no emoji in Quick Actions,
  Home container width > 1200px at 1440. Run the full suite and compare screenshots
  of the other pages (Patients, History, Live ER, Statistics, Settings) before/after
  to prove they are unchanged.

## Risks / things to confirm

1. **Widening via `body:has(...)`.** `:has()` is supported in current Chrome/Edge/
   Firefox; confirm the air-gapped hospital browsers are modern. Fallback: add a
   `home-active` class from `showSection()` instead (same effect, no `:has`).
2. **Shared checkout.** Another Claude session also works in this repo
   (branch `directory-api-v1-1-compat`). Home work should happen on this branch
   via a separate worktree, to avoid switching the shared working tree under it.
3. **Hero text readability** at 1920px (wider crop). Mitigated in HD-2 by checking
   all three themes.
4. **Out of scope unless you say otherwise:** hospital/site name in the header,
   Recent Activity and System Status panels, a 3-column lower grid.
